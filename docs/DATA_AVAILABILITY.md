# Data availability

Raw GOTTA Prototype photometry is governed by the GOTTA Collaboration data policy and is not included in this repository or its releases. This restriction is separate from the availability of the analysis code and derived validation products.

The repository contains the scripts, software versions, random seeds, split identifiers, predictions, corrected feature tables, GP held-out products, and other derived validation outputs used for the revised analysis. Scripts requiring restricted GOTTA inputs identify those requirements explicitly.

The ZTF light curves used in the analysis were obtained from the public IRSA ZTF light-curve service. Locally downloaded copies are not committed to this repository.
